# Estudio de Traducciones en Japonés (CiNii: 1850-1920)

## 1. Metodología y Palabras Clave
Se han identificado traducciones mediante la presencia de términos específicos en los campos de título y autoría para registros en japonés.

| Término | Significado aproximado |
| :--- | :--- |
| 訳 | Traducción / Traducido por |
| 翻訳 | Traducción (término formal) |
| 訳者 | Traductor |
| 共訳 | Cotraducción |
| 全訳 | Traducción completa |
| 和訳 | Traducción al japonés |
| 抄訳 | Traducción abreviada |
| 対訳 | Edición bilingüe / paralela |
